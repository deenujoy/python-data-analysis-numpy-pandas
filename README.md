# Python DA Assignment 1: Data Analysis using NumPy and Pandas

## 📖 Overview
This project demonstrates fundamental data analysis operations using **NumPy** and **Pandas**.  
It covers array creation, slicing, indexing, and basic statistical computations, followed by data manipulation and exploration using Pandas Series and DataFrames.

---

## 🧮 NumPy Array Operations
- Create and inspect 1D and 2D arrays.
- Perform temperature conversions (Celsius → Fahrenheit).
- Compute max, min, and mean values.
- Slice arrays to extract specific days and weeks.

---

## 🐼 Pandas Series
- Create a Series with custom indices.
- Perform indexing and slicing using `loc` and `iloc`.
- Apply boolean filtering and modify Series values.
- Compute CGPA from marks.

---

## 📊 Pandas DataFrame
- Create a DataFrame for transaction data.
- Explore data using `head()`, `tail()`, `info()`, and `shape`.
- Filter, group, and aggregate data.
- Add and remove columns dynamically.

---

## ⚙️ Technologies Used
- Python 3.x  
- NumPy  
- Pandas
